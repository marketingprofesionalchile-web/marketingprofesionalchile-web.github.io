# Marketing en Chile

Sitio web estático listo para publicar gratis con GitHub Pages.

## Archivos
- `index.html`
- `styles.css`
- `script.js`

## Antes de publicar
Busca `contacto@marketingenchile.cl` en `index.html` y reemplázalo por tu correo real.

## Publicar como marketingenchile.github.io
1. Crea o usa una cuenta de GitHub.
2. Crea un repositorio público llamado exactamente:
   `marketingenchile.github.io`
3. Sube los tres archivos de esta carpeta a la raíz del repositorio.
4. En GitHub, entra a Settings > Pages.
5. En "Build and deployment", selecciona "Deploy from a branch".
6. Elige la rama `main` y la carpeta `/ (root)`.
7. Guarda.

La dirección será:
https://marketingenchile.github.io
